# يومياتي (sabahdaily)

تطبيق يوميات ومهام عربي في ملف واحد (`index.html`)، والبيانات مشفّرة (AES-GCM) وتتزامن عبر Firebase.

## الميزات
- مهام اليوم بثلاث حالات (تم / جزئي / لم يتم)، وترتيبها بالسحب أو بالأسهم، ونسبة إنجاز
- صلوات المسجد، ورد اليوم، اقتراحات مهام، ونقل مهام أمس اللي ما خلصت
- يوميات نصية، وأرشيف فيه بحث
- **التحديات (جديد):**
  - نوعين: 🚫 **ترك عادة**، العداد يزيد كل يوم لحاله وتصفّره الانتكاسة. و🌱 **تعلّم / عادة جديدة**، تعلّم على كل يوم تنجز فيه
  - المدة: 30 يوم، 90 يوم، سنة، أو عدد أيام تختاره أنت (حتى 1000)، وتقدر تحدد تاريخ البداية
  - حلقة تقدّم، وشبكة أيام تقدر تضغط عليها عشان تعدّل الأيام اللي فاتت، وأطول سلسلة، وعدد الانتكاسات، وتاريخ النهاية
  - احتفال عند المراحل (3، 7، 14، 21، 30، 40، 60، 90، 100… 365) وعند ما يكتمل التحدي، وزر "كرّر التحدي"
  - شريط مختصر للتحديات النشطة في صفحة "اليوم" فيه زر ✓ سريع
- **تصميم مضغوط لقائمة المهام (جديد):** صفوف أنحف، وأزرار الحالة مجموعة في شريط صغير، وأسهم الترتيب صغيرة
- 3 ثيمات، وإعدادات الساعة والمنطقة الزمنية، ونسخة احتياطية مشفّرة (التصدير والاستيراد يشملون التحديات)
